Parameter Fungsi Linear

Bentuk Umum: f(x) = ax + b

Persamaan Terbentuk:
f(x) = x + 3

Fungsi linear membentuk garis lurus pada bidang Kartesius.

• a menentukan kemiringan garis (gradien).

• b menentukan lokasi perpotongan sumbu Y.

Simulasi Visual (GeoGebra Grid Style)

Pertidaksamaan Linear & Daerah Penyelesaian

Simulasi menemukan Daerah Himpunan Penyelesaian (DHP) dari sistem pertidaksamaan linear.

Sistem Pertidaksamaan

Garis 1: 2x + y ≤ 8
Garis 2: x + 2y ≤ 10
Syarat Non-Negatif: x ≥ 0, y ≥ 0
Fungsi Objektif Z: Maksimumkan Z = 3x + 4y

Area yang diarsir merupakan Daerah Himpunan Penyelesaian (DHP)
